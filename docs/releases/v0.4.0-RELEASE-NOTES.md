# Personal OS v0.4.0 — Source Release Candidate

**Status:** Source candidate for approval. This is not a GitHub release and does not mean the existing production service has been upgraded.

## Included

- Invitation-based web registration backed by a trusted local CLI, atomic invitation claim, and transactional account/session creation.
- User-scoped Task, Knowledge, Chat, Review, Proposal, Agent and Provider authorization improvements.
- Manual Task and approved AI Proposal writes routed through Task Service contracts with transaction and idempotency controls.
- Review Task Summary boundary and protection against stale asynchronous reads replacing current form input.
- Fail-closed schema revision guard before production startup side effects.
- Web denial of instance-level backup/export actions and user-owned Provider credential selection.
- Windows self-hosted workflow, installation and recovery guidance plus engineering evidence.

## Verification boundary

The source candidate was exercised on the same Windows host using isolated temporary directories, synthetic SQLite data and Mock Provider tests. See [release approval checklist](RELEASE_CANDIDATE_CHECKLIST.md) and [engineering evidence](../portfolio/PROJECT_EVIDENCE.md) for the command-level evidence and limitations.

The candidate is not evidence of a fresh-machine install, repaired production Windows ACLs, an upgraded production service, public cloud deployment, high concurrency, or real Provider quality. The formal Windows ACL repair remains pending; the existing service on port 8000 is not confirmed as v0.4.0.
