# 后台生命周期复盘：Stability & Lessons

v0.3.2 正式维护记录。用户确认本轮验收完成；本文仍为完整事故记录唯一来源，并保留证据边界和未知根因。

## 1. 故障现象

用户点击 X 关闭启动窗口后 FastAPI 消失，8000 无监听，本机健康连接失败，Tailnet 502。旧任务 Ready，历史退出码 3221225786 / 0xC000013A。它是控制中断线索，不足以唯一识别终止者。

## 2. 历史调查局限

Git 无提交，无法按版本或提交重建 v0.2.x/v0.3.0 启动实现。文件时间不能证明引入版本。故障时段 Task Scheduler Operational 记录不足，无法确定来自关窗、显式停止或其他进程。正常菜单退出不停止服务，不能据此推论 X 关闭安全。

## 3. 主要失败路线

| 路线与动机 | 实际问题、证据与避免方法 |
| --- | --- |
| A：菜单退出/终端控制测试，快速检查停止逻辑 | 不能代表用户点击 X；早期验收过度外推，用户仍复现。以后严格按真实操作验收。 |
| B：InteractiveToken 推断，解释桌面依赖 | 要求用户登录不等于依赖 PowerShell 窗口；过早归因无证据。分开登录、控制台、进程生命周期。 |
| C：WinSW，寻求 SCM 监督 | 引入发行来源、签名、Defender、管理员及供应链核验，最小实验却未做。并非 WinSW 本质不安全，而是当时无需提前采用。 |
| D：LocalService/任务 SID/ACL，追求无登录及最小权限 | 扩大为共享身份、主密钥、WAL/SHM、媒体与备份权限问题。路线本身不错误，但超出当时关窗需求，本轮停止。 |
| E：备份保护现场 | Codex 可见目录与用户检查不一致，未实机确认便报告完成不合格。后来双方读取用户创建的 host-verified 快照，个别路径状态仍有差异；以后核对存在性、哈希、完整性和用户可访问性。 |
| F：python -c 临时诊断 | 用户记录引号错误导致 NameError；本轮未获得原始命令，细节未知。复杂诊断用可审查脚本，验证实际 shell 引号，避免输出秘密。 |
| G：候选 XML 拒绝覆盖，保护原文件 | 用户记录已有文件使操作中断，本轮未复现，不能等同候选任务已注册。区分文件、任务与运行状态，幂等复用已验证现场而不盲目覆盖。 |
| H：缺少 Git 基线，早期本地快速开发 | 当前 git log 明确无提交，无法回溯有效版本。检查忽略规则、精确提交清单、凭证和个人数据排除后，建立 v0.3.2 本地基线，不自动 push。 |

## 4. 成功的最小实验

用户通过 Start-Process 使用现有 backend/.venv/Scripts/pythonw.exe、原 backend/scripts/windows_service.py，工作目录 backend。关窗后重新检查实验进程，本机及 Tailnet 健康 status=ok、database=ok。本轮开始仍看到该实例监听。

该组合同时改变可执行文件和启动方式，不证明 pythonw 是历史故障唯一根因。新版管理器复用该组合；登录自启可调用管理器 Start，再分离启动，不假定任务直接运行 pythonw 完全等价。

## 5. 已知与未知

- Confirmed：用户亲自确认原无控制台实验关窗成功；pythonw 存在，文件日志不依赖控制台；旧任务当前用户 Interactive。
- Confirmed：自动化模拟检查独立启动、重复启动、外来/不健康监听拒绝与精确停止；不代表实际启停。
- Confirmed：Windows PowerShell 5.1 直接读取无 BOM 中文脚本发生解析错误，补 UTF-8 BOM 后专项测试通过。这不能解释历史控制中断。
- Inferred：无控制台启动可能改善窗口生命周期，组合实验不能隔离因果。
- Unknown：历史中断发起者、旧版本实现、全部文件系统视图是否一致。
- Pending Verification：登录自启、Windows 重启及异常恢复。本轮发布基于用户确认验收完成，不将其记为 Codex 执行的实机测试。

## 6. 可复用原则

1. 最小复现优先，每次尽量只改一个变量。
2. 先识别网络、进程、认证与数据故障边界，再改架构。
3. 单元测试、部署健康、用户 E2E 分层，不互相冒充。
4. 唯一数据源；备份实际落盘、用户可读并可恢复。
5. 幂等操作与状态检查，身份不可核验时不误杀。
6. 最小权限、显式授权、保留定义与安全回滚。
7. Git 基线经隐私检查与用户确认，保持版本可追溯。
8. 日志和健康真实有效，进程存在不等于数据库健康。
9. 无证据标未知，不宣传永久修复或永不掉线。

## 7. 剩余限制

路线适用于用户登录后的 Windows；关机、睡眠、注销、网络中断不保证访问。分离后的 pythonw 不受短期登录任务持续监督，其 Ready 不等于网站离线，RestartCount 也不能当作应用异常恢复。

启动互斥锁仅在当前登录 Session，非跨用户全局服务锁。显式停止会中断未完成请求，强制退出可能没有退出日志，只能由非敏感 run-state 提示缺少清理。进程命令行不可读取时拒绝停止，不扩大权限。

本轮未注册任务、改 ACL、迁移数据库或调用模型；正式发布与本地 Git 提交须等待用户验收。
